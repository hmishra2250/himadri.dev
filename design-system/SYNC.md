# Sync record

This folder is the design system for himadri.dev and the source of truth for the site. It began as a read-only copy of the claude.ai/design project **himadri.dev Design System** (project `af224db4-0b15-40ac-ac33-6e67b1ffaeb2`, v2, pulled on 2026-10-06) and has since been extended here.

## Differences from the claude.ai/design project

- `components/additions.css` and the v3 sections of `readme.md` exist only here: framed panels with cut-in labels, tiles, the ledger, one-liners, metric tiles, reference groups, years, the hero split, social brand marks, the footer band and the document viewer.
- `readme.md` content rules were rewritten to match the current site; `SKILL.md` names the role as AI engineer.
- `components/identity/ContactBlock.jsx` no longer defaults to an email address.
- Not copied or not committed: `assets/og-image.png` (legacy), `uploads/` (reference screenshots, truncated by the 256 KiB read limit), `_ds_manifest.json`, `_adherence.oxlintrc.json`, `thumbnail.html`, `.thumbnail` (generated by claude.ai/design), and `ui_kits/` (the retired six-page site; kept locally only).

To bring claude.ai/design up to date, run `/design-sync` in Claude Code from this repository; it uploads only after you approve the plan.

## Previewing the reference cards

The preview cards load React and Babel from unpkg and fonts from Google Fonts, so serve the folder over HTTP:

```bash
python3 -m http.server 4321 --directory design-system
# then open http://localhost:4321/components/work/work.card.html
```
