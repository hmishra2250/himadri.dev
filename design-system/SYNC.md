# Sync record

This folder is the design system for himadri.dev. The claude.ai/design project **himadri.dev Design System** (project `af224db4-0b15-40ac-ac33-6e67b1ffaeb2`, v2) is the source; this folder follows it.

## History

- **6 October 2026:** pulled read-only (v2), then extended here as "v3": framed panels with cut-in labels, tiles, a ledger, one-liners, work cards and more, in `components/additions.css`. The v3 additions were never pushed to claude.ai/design.
- **11 October 2026:** pulled again and the site rebuilt on v2. The tokens and `components/components.css` match the project exactly. The v3 additions are retired; `components/additions.css` now holds only what the one-page site needs that v2 does not define (see the readme, "Site additions").

## Differences from the claude.ai/design project

- `readme.md` is the project's readme with a note on content rules at the top and two sections at the end ("How the site uses it", "Site additions").
- `components/additions.css` exists only here.
- `SKILL.md` names the role as AI engineer.
- `components/identity/ContactBlock.jsx` no longer defaults to an email address.
- Not copied or not committed: `assets/og-image.png` (legacy), `uploads/` (reference screenshots, truncated by the 256 KiB read limit), `_ds_manifest.json`, `_adherence.oxlintrc.json`, `thumbnail.html`, `.thumbnail` (generated by claude.ai/design), and `ui_kits/` (kept locally only, git-ignored).

## Pulling and pushing

Change the design in the claude.ai/design project, then pull the changed files here and rebuild the affected components in `src/components/ds/`. To push the site additions back to the project, run `/design-sync` in Claude Code from this repository; it uploads only after you approve the plan.

## Previewing the reference cards

The preview cards load React and Babel from unpkg and fonts from Google Fonts, so serve the folder over HTTP:

```bash
python3 -m http.server 4399 --directory design-system
# then open http://localhost:4399/components/work/work.card.html
```
