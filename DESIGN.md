# Design

The design of himadri.dev lives in `design-system/`. Read `design-system/readme.md` (the claude.ai/design project's v2 readme, with how the site uses it and the site additions) and `design-system/SYNC.md` (how this repository follows the project). Content, messaging and confidentiality rules live in `AGENTS.md` and are enforced by `src/lib/validation.ts`.

Until October 2026 this file described the six-page site (Go Sans, Work, Notes, About, Contact). That design is retired; git history has it.
