## Controlled routing study

The comparison is a state-matched routing card versus no card across two agent clients, each with 59 matched positive/hard task pairs. It covers a selective rerun of five changed capability states, not the whole journey inventory.

| Client   | Baseline: correct route and task complete | Treatment: correct route and task complete |
| -------- | ----------------------------------------: | -----------------------------------------: |
| A        |                                     44/59 |                                      48/59 |
| B        |                                     46/59 |                                      51/59 |
| Combined |                                    90/118 |                                     99/118 |

The combined rate rises from 76.27% to 83.90%. The absolute difference is 9/118, or 7.63 percentage points, displayed as approximately 8 percentage points. Equal pair counts allow this pooled descriptive comparison without mixing unlike outcome definitions.

This is the joint routing-and-completion outcome, not tool uptake, a generic usability score or signup conversion. Task completion alone rose from 113/118 to 117/118; raw tool uptake was unchanged in aggregate. The reported adjusted p-value was 0.25 per client: the observed improvement is directional, not statistically conclusive. No pooled significance claim is made. Safety and answer quality were assessed separately, not folded into this number.
