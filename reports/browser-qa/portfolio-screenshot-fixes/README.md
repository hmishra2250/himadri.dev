# Portfolio screenshot fix QA

Date: 2026-04-30
Scope: visual issues reported from local screenshots around hero metrics, proof metrics, and the Interview Me chat surface.

## Findings from screenshots

- Hero metric values wrapped awkwardly inside the 2 by 2 proof panel.
- Proof Wall metric cards were too tall and left large empty areas.
- Live assistant heading and shell were too dominant when embedded in Interview Me and homepage preview sections.

## Fixes checked

- Metric values with arrows now render as structured number, arrow, number groups.
- Hero metric typography is smaller so values fit better in narrow proof boxes.
- Proof Wall cards are shorter and more balanced.
- Live assistant supports a compact embedded presentation for homepage preview and a smaller heading on the full route.
